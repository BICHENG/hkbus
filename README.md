# hkbus · 城巴 B3 系列實時班次

香港城巴 B3 / B3A / B3X 三條跨境線的實時到站顯示屏。純靜態頁，雙擊 `bus.html` 就能開，
不需要任何服務器、API key 或後端。

**線上**：<https://bicheng.github.io/hkbus/>（GitHub Pages，公開倉庫 `BICHENG/hkbus`，從 `main` 分支根目錄發布）
舊的 `/b3a-bus` 地址不會跳轉，已失效。

- [2D 點陣班次屏](bus.html) — 兩個收藏（去程／返程）各自選線與站；下一班、在途車輛、沿線進度（時間軸或里程軸）
- [3D GIS 版](citybus_gis.html) — Cesium 1.133 + 地政總署 3DVM 真傾斜攝影 + KMD 影像，線路貼公路走，車輛沿線推算

3D 版要 https 才能解出傾斜攝影紋理；`file://` 開啟會有提示（本機可用 `python -m http.server` 起個本機伺服器）。
手機上會自動進「輕量模式」：跳過傾斜攝影、渲染倍率降到 1，並提示改用 2D 班次屏；
桌面上想強制輕量／完整可加 `?lite=1` 或 `?full=1`。

## 頁面能做甚麼

### 2D 點陣屏

- **兩個收藏**：去程與返程各自獨立設定（路線 + 起點站 + 終點站），互相不綁定。
  方向由站序自動判定：起點在前的那個方向就是去程方向。
- **站點頂替**：同一地點在兩個方向常是不同站台（富泰邨 `003261` 與富泰商場 `003262` 相距 55 m），
  方向裡沒有這個站時會就近頂替並標明距離。
- **線路進度**：橫軸可切時間軸或里程軸，站點按這一段實際要走的時間或里程排開，車標按到站時間插值。
- **在途車輛**：每班車用花括號列出接下來幾個站還差多少時間與里程。

### 3D GIS 版

- 真實公路折線（逐段切分到站），去程與回程側向錯開，每段一個方向箭頭。
- 地政總署 3DVM 真傾斜攝影 + KMD 衛星影像，四個預設機位（全線走廊、富泰邨、深圳灣口岸、屯門市中心）。
- 在途車輛沿真幾何移動，快到站時輕微呼吸；點 HUD 裡的班次可以跟隨它；「動效」按鈕可整體關掉。
- HUD 如實顯示各項來源狀態（到站／傾斜攝影／影像底圖／路線幾何／3DVM 探針／階段／跟隨／首屏），出錯也會直接寫在畫面上。

## 資料從哪裡來

| 用途 | 來源 |
| --- | --- |
| 到站時間、站序、站名座標 | [rt.data.gov.hk](https://rt.data.gov.hk/v2/transport/citybus) 城巴 API（CORS 開放） |
| 班距、首末班、道路走向 | 運輸署交通通告（`TA_CTB B3 Series_20250501_C.pdf`、`TA_B3A_Chi.pdf`） |
| 路線總長 | 運輸署 CSDI「巴士路線」數據集 `FB_ROUTE_LINE` 的 `Shape_Leng` |
| 逐段折線與逐段里程 | OSM 路網，經 [OSRM](https://router.project-osrm.org/) 按站序取得後逐段切分（`geometry.js`） |
| 逐段耗時 | 站到站 ETA 配對後的實測中位數（頁面自己也會持續修正） |
| 3D 傾斜攝影 | 地政總署 3D 視覺化地圖（3DVM, mesh model） |
| 影像底圖 | KMD World Imagery |

## 這是 Lecture 8 作業的延伸

Lecture 8 給的起始檔 `CDT501_Lecture8_bus-board.zip`（內含 `bus-board/bus.html`）是一個兩欄的
「下一班 B3A」看板：用 `rt.data.gov.hk` 的 ETA 接口輪詢兩個上車點（富泰邨 `003261`、深圳灣口岸 `003208`），
每 30 秒刷新。本頁做的是同一件事的完整版：

| | 起始檔 | 本頁 |
|---|---|---|
| 內容 | 兩個上車點的下一班 | 三條線六個方向，任選起終點，兩個收藏各自設定 |
| 語言 | 英文為主 | 中英對照，英文用點陣 |
| 位置 | 只有到站時間 | 逐段里程、沿線進度、在途車輛推算、每車到各站剩餘時間與里程 |
| 空間 | 無 | 3D 版：真傾斜攝影 + 真實公路折線 + 車輛沿線移動 |
| 資料層 | 頁內直接 fetch | `busdata.js` 共用層（班次身份、跨站配車、快取），2D/3D 同一份 |

起始檔裡那句 `rmk_en`（接口的英文備註，例如「分站不停 / Short stop」）也保留了，出現在到站表的目的地下方。

## 幾件要講清楚的事

- **車輛位置是推算的，不是實時定位。** 城巴 API 不提供車輛座標。
  頁面用「上游站到站時間」和「下游站到站時間」之間的插值，估計車走到哪裡、走了幾成。
- **逐段耗時來自觀測，不是官方時刻表。** 官方交通通告只有班距與首末班，沒有逐段時間。
  每一段配對上号就收一個樣本，取中位數當常態；交通擠塞時會慢慢變。
- **逐段里程是 OSM 路網距離，不是運輸署官方路網。** 官方 GML（273MB）下不完整——伺服器會掐長連接、
  `accept-ranges` 為 null 無法續傳。改用 OSM 經 OSRM 取線：回程方向與官方 `Shape_Leng` 幾乎一致
  （B3 21.27km vs 21.30km），去程方向 OSM 長 15~20%。頁面標為「里程用 OSM 路網」，不假裝是官方數字。
- **接口沒有整條線一次拿完的端點。** 「全量快照」是頁面層一次併發拉所有站再自己合成。
- **班次身份用接口給的到達次序 `eta_seq`，不是到站時間。** 到站時間是會移動的預測；
  拿它當身份會把同一班車拆成多條記錄。

- 點陣尺寸：`s3` 7px（路線牌）、`s2` 5px（到站時間）、`s1` 3px（英文站名）、`s0` 2px（窄屏英文）。
- 圓角：面板 10–14px、按鈕 6px、徽章 8px。
- 間距：面板內距 13–20px，兩頁都以此為準。

## 五分鐘演示腳本

1. **（30 秒）打開 2D 頁**：說明這是 Lecture 8 的作業——用城巴公開 API 做實時班次屏，
   兩個收藏（去程／返程）可以自己設線設站，預設是 B3A 富泰邨 ⇄ 深圳灣口岸。
2. **（1 分鐘）切到 3D 頁**：指出線不是兩點連線，而是真的公路折線（OSM 路網按站序切到每個站），
   每段一個箭頭，去回程側向錯開；背景是地政總署的真傾斜攝影。
3. **（1 分鐘）誠實說明**：車輛位置是「用到站時間插值推算」，不是實時定位；
   逐段里程是 OSM 的，不是運輸署官方數據，而且去程方向比官方長 15–20%。HUD 上都寫著。
4. **（1 分鐘）技術亮點**：班次身份用接口的到達次序而不是到站時間（到站時間會漂移，會把同一班車拆成兩條）；
   相鄰兩站配對有物理下限（直線距離 ÷ 最高車速），否則長途段會被配成 1 分鐘的假段；
   逐段耗時是觀測中位數，官方通告只有班距沒有逐段時間。
5. **（30 秒）收尾**：兩頁共用同一份資料層，離線有快取，線上在 GitHub Pages，程式碼在這個倉庫。

## 檔案

```
bus.html          2D 點陣屏
busdata.js        共用資料層：快取、班次身份、跨站配車、位置推算、逐段耗時表（2D／3D 共用）
busroutes.js      靜態元資料：官方路線長度、班距首末班、逐段耗時基線、逐段里程（OSM）、預設上車組合
geometry.js       逐段公路折線與逐段里程（自動生成，勿手改）
citybus_gis.html  3D GIS 版
3D-PLAN.md        3D 版的 WBS 與 CCPM 計劃（執行清單與台賬）
```
